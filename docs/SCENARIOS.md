# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

## 缺口桶反例

A12、B11、C9，只观测AB=4、AC=3（缺BC）：缺口桶不隔离，标记PARTIAL；BC按自由变量枚举得联合区间[19,25]，上界25与三组交集齐全时相同，不被压低；把缺项当零会伪造[25,25]，整桶剔除则少算19–25的已观测客次。回填BC=2并重新定界后转为COMPLETE，区间收窄为[23,25]，批次finalized方可正式归档。仅观测一对、零对交集，或附带三方T观测时，同一Venn枚举口径均成立；无解（如A=B=C=100、AB=AC=80、BC=0）仍按CONSTRAINT隔离。
