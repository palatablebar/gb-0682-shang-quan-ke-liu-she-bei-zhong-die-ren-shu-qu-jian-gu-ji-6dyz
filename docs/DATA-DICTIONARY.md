# 客流观测与区间

区域人数与两两交集必须是非负整数，单位人或千人。东门、中庭、西门映射为A、B、C。时间先转UTC后形成小时桶；非整点观测向下归入所在UTC小时桶。同一观测按version选择最高版，矛盾同版隔离。

最多三个区域。两区域无交集观测时联合人数为[max(A,B),A+B]；已知交集I时为A+B-I。三区域需要全部两两交集方可正式定界；三方交集T下界为max(0,AB+AC-A,AB+BC-B,AC+BC-C)，上界为min(AB,AC,BC)。联合人数为A+B+C-AB-AC-BC+T。区间无可行整数时整桶隔离。输出上下界，不估算未经观测的精确人数。日汇总是分桶客次的上下界相加，不宣称是全天独立人数。

## 缺口小时桶裁决（缺失两两交集）

缺一组两两交集时**不整桶剔除、也不把缺项当零**：已观测的区域边际与交集仍是有效证据，剔除会系统性少算日汇；缺项当零则把上界压成假精确。正确口径是把未观测交集当作自由变量，在七个Venn原子（仅A/仅B/仅C、AB-only、AC-only、BC-only、三方T）的全部可行整数组合上取联合人数极值——下界保留已观测证据能支撑的最小联合人数，上界允许未观测重叠为零，因而**未观测部分不压低上界；已观测交集只通过对应原子约束进入一次，不重复相加**。

缺口桶标记 `PARTIAL`（完整桶为 `COMPLETE`），参与估界页面展示与日汇区间求和，但批次 `finalized=false`：回填交集并重新定界前不能进入正式日汇，归档导出返回409（PARTIAL_RUN）。矛盾观测（无可行整数）仍整桶隔离，与缺口桶严格区分。定界只依赖观测集合本身：乱序记录到达得到同一区间；运行幂等键由输入字节、参数与规则版本计算，同一批观测重试得到同一run_id、同一区间宽度，不重复加宽。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

三方交集仅在A、B、C三个区域齐全时适用，类型triple的left必须为ABC，right必须为空。

支持区域固定为A、B、C；其他区域标识拒绝，防止三方ABC记录关联到另一组区域。
